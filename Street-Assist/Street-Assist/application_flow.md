StreetAssist: Unified Product Flow & Dual-Role Management

StreetAssist is designed as a single, cohesive system where every user can both request help and offer help without managing separate accounts or logins. This document outlines the core journey and the logic behind this dual-role approach.

1. Unified Registration & Onboarding

The experience begins with a single entry point.

Unified Account: Each user registers with one set of credentials.
Two-Step Onboarding:
Step 1 (Basic Setup): Users complete their profile with name, email, and security details. At this stage, every user can request help immediately.
Step 2 (Helper Setup - Optional): Users can choose to add their skills, such as technical or physical assistance, along with a short bio. This step enables them to help others.
Single Login: A single email and password or social login provides access to all features.
2. The Unified Dashboard (Helper Mode System)

The core experience is centered around a single dashboard with a consistent navigation bar (Home, Help-Zones, Requests, Rankings, Profile).

Requesting Help (Always Available)
Primary Goal: Get help quickly when needed.
Interface: The "Request Help" action is always available to every user.
Flow:
Click "Request Help" → A modal opens with categories.
Select a category → View sub-categories or specialists.
Submit the request → The system searches for nearby helpers.
Live tracking → Monitor the helper’s arrival in real time.
Helper Mode (Turned ON)
Primary Goal: Allow users to help others and receive tasks.
Flow:
Turn on Helper Mode → Incoming help requests appears in incoming request interface.
Browse requests → View details such as location and issue.
Accept a request → Access full task details.
Complete the task → Earn points and receive payments.
3. Help-Zones: The Trust Layer

Help-Zones such as campuses or workplaces act as a trust filter.

Requesters can mark requests as "Zone-Only" so only members within that community can see them.
Helpers can focus on these requests, knowing they are assisting someone within a familiar environment.
4. Gamified Motivation (Shared Progression)

Progress is tied to the individual account, not the role.

Helping earns points and increases Helper Level (such as Pro or Elite).
Requesting and providing feedback earns community points that can be used for service benefits.
Features like 7-Day Streaks and Weekly Leaderboards encourage consistent participation and visibility within the platform.
5. Transaction & Completion

Each interaction ends with a clear and transparent process.

Requester side: Payment and review screen for completing transactions, applying rewards, and rating the helper.
Helper side: Task completion summary showing earnings and progress updates.

Summary: StreetAssist uses a simple Helper Mode system within a unified account structure. Users can always request help, while enabling Helper Mode allows them to receive and respond to incoming requests. This approach removes friction and supports a natural, community-driven experience where users can both give and receive help.
